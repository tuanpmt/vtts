Text-to-speech that runs on a microcontroller

vtts turns text into speech entirely on an ESP32: text normalization, pronunciation, an int8 neural voice and the vocoder all run on the chip. No cloud, no network, no Linux. Every clip on this page was generated by an ESP32-P4 and sent back over its serial port.

Listen

Every clip is the chip's own PCM output, sent back over the serial port and only compressed to MP3. Pick a language, then play any model on any sentence.

Voices

Every voice comes in two tiers. New languages plug in as front-end modules on a shared, versioned token set, so the runtime and firmware stay the same.

Get started

gh release download v0.3.0 -R tuanpmt/vtts -p '*.vtts' -D models
cd firmware/esp32
BOARD=nano ./build.sh ../../models/vtts-vi-s-v0.1.q8.vtts \
  ../../models/vtts-vi-m-v0.2.q8.vtts -p PORT flash monitor

BOARD is panel, nano or s3. Type a sentence on the serial console and the board speaks it. Full instructions are in the README.
